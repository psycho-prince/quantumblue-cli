CLI + Runtime Discovery Engine

The QuantumBlue CLI is the command-line interface to the Continuous Cryptographic Posture Management (CCPM) platform. Hybrid PQC signing (ML-DSA-65/ML-KEM-768), RFC 3161 timestamping, CBOM generation, TLS certificate scanning, and eBPF runtime discovery — all from the terminal.

$ go install github.com/psycho-prince/quantumblue-cli@latest

What the CLI Does

Designed for security teams, platform engineers, and developers migrating to post-quantum cryptography.

Hybrid PQC Signing

Combines classical signatures (Ed25519 / RSA-4096) with NIST FIPS 204 ML-DSA-65 to protect against both classical and quantum attacks. Generates hybrid signatures that legacy clients can still verify.

RFC 3161 Timestamping

Binds files to globally synchronized Time Stamp Authorities (TSA), creating cryptographically immutable proof of file existence — critical for legal evidence and chain-of-custody workflows.

CBOM Generation

Generates Cryptographic Bill of Materials (CBOM) in CycloneDX 1.6 JSON format. Scans source code and runtime environments for legacy crypto — RSA, ECC, SHA-1 — and produces auditable inventory reports.

TLS Surface Scanning

Scans any domain's TLS certificate to detect quantum vulnerability. Reports HNDL (Harvest Now, Decrypt Later) risk grade, algorithm, key size, and detected PQC algorithms. The lead-gen entry point to the platform.

eBPF Runtime Discovery

Phase 2 capability. When attached to Linux hosts, the eBPF sensor observes real cryptographic library calls (OpenSSL, BoringSSL, Java Crypto) in production — no agents, no code changes. Builds the Cryptographic Asset Graph from ground truth.

Shift-Left Guardrail

Phase 4 capability. Integrates with GitHub and GitLab to block pull requests that introduce legacy cryptography. CLI mode for any CI pipeline. Stops new cryptographic debt from entering production.

Cryptographic Specifications

Strict implementation of published standards without proprietary protocol modifications.

NIST FIPS 204

ML-DSA-65 Signature

Primary post-quantum digital signature algorithm (formerly Dilithium3) providing Security Category 3 (equivalent to AES-192 resistance).

NIST FIPS 203

ML-KEM-768 Encapsulation

Module-Lattice-Based Key-Encapsulation Mechanism (formerly Kyber768) utilized for secure quantum-safe key exchange.

IETF RFC 3161

Trusted Timestamping

Internet X.509 Public Key Infrastructure Time-Stamp Protocol binding SHA-256 hashes to trusted clock authorities.
